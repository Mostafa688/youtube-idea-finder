# 🎯 مولّد أفكار فيديوهات يوتيوب

أداة مجانية ومفتوحة المصدر بتشتغل بالكامل جوه متصفحك (مفيش سيرفر خلفي، ومفيش بياناتك بتتخزن في أي مكان غير جهازك).

**الفكرة:** بتحط لينكات قنوات منافسينك، والأداة:
1. بتجيب كل الفيديوهات اللي نزلوها في آخر فترة (شهر لحد 6 شهور، إنت بتحدد).
2. بتحسب أي فيديو "ضرب" فعلًا نسبة لمتوسط أداء نفس القناة (مش بس أكبر عدد مشاهدات مطلق، عشان القنوات الكبيرة والصغيرة يتقاسوا بعدل).
3. بتبعت الأنماط دي لـ Gemini AI (مجاني من جوجل) وهو بيقترحلك 5 أفكار فيديو جديدة مناسبة لقناتك، وكل فكرة معاها تقييم احتمال نجاح من 0 لـ100 مبني على قوة الدليل من البيانات الفعلية.

## 🚀 جرّب الأداة

بعد ما تفعّل GitHub Pages (خطوات تحت)، هتلاقي الأداة شغالة على:

```
https://<اسم-حسابك>.github.io/youtube-idea-finder/
```

## 🔑 المفاتيح المطلوبة (كلهم مجانيين)

### 1. مفتاح YouTube Data API v3
1. افتح [Google Cloud Console](https://console.cloud.google.com/).
2. اعمل مشروع جديد (أو استخدم موجود).
3. من القائمة الجانبية: **APIs & Services → Library**، دوّر على **YouTube Data API v3** وفعّلها (Enable).
4. من **APIs & Services → Credentials**، دوس **Create Credentials → API Key**.
5. انسخ المفتاح وحطه في الأداة.

> الكوتة المجانية 10,000 وحدة في اليوم — كل تحليل لقناة بياخد تقريبًا 5-10 وحدات، يعني تقدر تحلل عشرات القنوات يوميًا من غير ما تدفع.

### 2. مفتاح Gemini API
1. افتح [Google AI Studio](https://aistudio.google.com/apikey).
2. دوس **Create API key**.
3. انسخ المفتاح وحطه في الأداة.

> Gemini API له باقة مجانية دايمة (مش تجربة مؤقتة) بحد استخدام يومي كويس، وده اللي بيخليها أنسب اختيار لأداة زي دي.

## 🌐 إزاي تفعّل GitHub Pages للريبو ده

1. من الريبو على GitHub، روح **Settings → Pages**.
2. تحت **Build and deployment**، اختار **Source: Deploy from a branch**.
3. اختار **Branch: main** و **Folder: / (root)**، واحفظ.
4. استنى دقيقة أو اتنين، وهتلاقي اللينك ظاهر فوق في نفس الصفحة.

## 🧠 إزاي بتحسب "احتمال النجاح"

الأداة بتحسب لكل فيديو `outlier_score = مشاهدات الفيديو ÷ متوسط مشاهدات نفس القناة في نفس الفترة`. رقم زي `×3.5` معناه الفيديو ده جاب 3.5 ضعف أداء القناة المعتاد — يعني موضوعه أو زاويته لامست حاجة الجمهور يحبها أكتر من العادي. الأنماط دي هي اللي بتتبعت لـ Gemini عشان يبني عليها الاقتراحات وتقييم النجاح.

ده تقدير مبني على بيانات حقيقية مش وعد مضمون — الهدف إنه يوجهك لاتجاهات مثبت إنها بتشتغل في مجالك، مش يضمنلك انتشار.

## 🔒 الخصوصية

- المفاتيح بتتخزن في `localStorage` بتاع متصفحك بس، وممكن تشيلها في أي وقت من زرار "تذكر المفاتيح".
- كل الطلبات بتروح مباشرة من متصفحك لـ Google (YouTube API و Gemini API) — مفيش سيرفر وسيط بيشوف بياناتك.

## 🛠️ التطوير المحلي

الأداة عبارة عن HTML/CSS/JS خام من غير أي build step. تقدر تفتح `index.html` مباشرة في المتصفح أو تشغّل أي سيرفر ستاتيك بسيط:

```bash
python3 -m http.server 8000
```
